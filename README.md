# Plant Watering AI — Colab → Streamlit

**Используется только** `jibrand/Plant-dataset` (`plant_dataset.csv`).

## Порядок демонстрации
1. Откройте `Plant_Watering_Numeric_Training.ipynb` в Google Colab и выполните все ячейки. Вы увидите очистку исходных категорий, нормализацию числовых признаков в отдельном эксперименте, генерацию синтетических числовых сценариев, обучение дерева, оценку и сохранение модели.
2. Для загрузки модели в Streamlit замените `model/irrigation_tree.joblib`, `model/metrics.json` и `data/plant_catalog.csv` файлами, полученными после повторного обучения (в архиве они уже включены).
3. Загрузите файлы корня проекта в GitHub, откройте https://share.streamlit.io и укажите `app.py`.
4. Для локального запуска: `pip install -r requirements.txt` → `streamlit run app.py`.

## Важная честная оговорка
В оригинальном Plant-dataset нет числовых показаний датчиков и подтвержденного решения «полить/не полить». Для обучения искусственно сгенерированы показатели и метки по правилу, зависящему от указанной в датасете категории полива. Ползунки **реально меняют вход обученной ML-модели**. Но качество на синтетическом тесте не является реальной точностью в агрономии. Числовые пороги демонстрационные; их нужно откалибровать по настоящим растениям и сенсорам.
